# 06 · Tools

Standalone utilities that are not part of the desktop or the shell.

| Chapter | Path | Purpose |
|---------|------|---------|
| focus | [`focus/`](focus/README.md) | Site blocker: dnsmasq and nftables, schedule timers, lock mode. Block and allow lists are linked to `~/focus/` |
| pgvector-demo | [`pgvector-demo/`](pgvector-demo/README.md) | A demo database for pgvector on the system PostgreSQL: embeddings table, HNSW index, nearest-neighbour queries |

Each tool keeps its own README with install steps and what is runtime state.
