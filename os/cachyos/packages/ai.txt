# Local LLM inference (Ollama + ROCm + Vulkan)
#
# ollama-rocm is the one that matters: plain `ollama` is a CPU-only build,
# and installing it alone leaves an AMD card completely unused. It pulls the
# ROCm stack below as dependencies. ollama-vulkan + vulkan-radeon are also
# installed as an alternate backend — see tools/ollama/README.md: Vulkan
# crashes on large prompts on this gfx1031 card, so ROCm is the one actually
# in use (tools/ollama/systemd/backend-rocm.conf), but the packages stay
# installed so `ollama-backend vulkan` can still switch back for testing.
#
# Do NOT use the upstream install.sh — see tools/ollama/README.md for why
# (it shadows the packaged binary and ships 7.4GB of CUDA libs useless here).
#
#   sudo pacman -S --needed $(grep -v '^#' os/cachyos/packages/ai.txt | awk '{print $1}')
# ─────────────────────────────────────────────────────────────────────────────
ollama
ollama-rocm
ollama-vulkan
vulkan-radeon
rocm-core
hip-runtime-amd
hsa-rocr
rocblas
rocsolver
hipblas
rocminfo
