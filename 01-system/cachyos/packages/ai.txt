# Local LLM inference (Ollama + ROCm + Vulkan)
#
# This is an optional, hardware-specific package set; it is not part of the
# desktop baseline. ollama-rocm provides the AMD ROCm backend, while
# ollama-vulkan + vulkan-radeon provide an alternate backend. See
# 05-ai/ollama/README.md before installing: the Vulkan backend is unstable on
# some gfx1031 workloads. Keep ROCm as the live backend.
#
# Do NOT use the upstream install.sh: it installs under /usr/local or /usr without checking for a
# packaged install, deletes $OLLAMA_INSTALL_DIR/lib/ollama, and creates its own user and unit
# (see 05-ai/ollama/README.md).
#
#   ollama, ollama-rocm and ollama-vulkan install side by side (the two backends
#   depend on ollama); which backend is live is chosen by the systemd drop-in
#   backend.conf (05-ai/ollama/README.md), so the list is safe to install in one transaction.
# ─────────────────────────────────────────────────────────────────────────────
ollama
ollama-rocm
ollama-vulkan
vulkan-radeon
rocm-core
vulkan-tools
hip-runtime-amd
hsa-rocr
