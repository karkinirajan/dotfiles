# Local LLM inference (Ollama + ROCm + Vulkan)
#
# This is an optional, hardware-specific package set; it is not part of the
# desktop baseline. ollama-rocm provides the AMD ROCm backend, while
# ollama-vulkan + vulkan-radeon provide an alternate backend. See
# 05-ai/ollama/README.md before installing: the Vulkan backend is unstable on
# some gfx1031 workloads. Install only the backend packages you intend to use.
#
# Do NOT use the upstream install.sh — see 05-ai/ollama/README.md for why
# (it shadows the packaged binary and ships 7.4GB of CUDA libs useless here).
#
#   Review and install selected packages individually; this list includes
#   mutually exclusive Ollama backend variants and is not a bulk install set.
# ─────────────────────────────────────────────────────────────────────────────
ollama
ollama-rocm
ollama-vulkan
vulkan-radeon
rocm-core
hip-runtime-amd
hsa-rocr
rocblas
rocsolver
hipblas
rocminfo
