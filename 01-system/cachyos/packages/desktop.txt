# Hyprland + Noctalia desktop packages
#
# Desktop session, host greeter, hardware integration, and the directly
# installed desktop applications on the primary CachyOS workstation.
#
# Install the combined baseline package lists using the interactive commands
# in the root README. That flow supports either paru or yay for AUR packages.
#
# Referenced directly by config:
#   hyprland hyprlock hypridle hyprpolkitagent   02-desktop/hyprland/hypr/*.conf
#   greetd noctalia-greeter uwsm                 active Noctalia greeter + UWSM session
#   sddm                                          installed, currently inactive fallback
#   noctalia                                   the bar/launcher/notifications
#   cachyos-wallpapers                          Noctalia's selected CachyOS Moon wallpaper
#   hyprsunset                                   scripts/nightlight-toggle.sh
#   hyprpm                                       plugin reload in autostart.conf
#   cliphist wl-clipboard                        autostart.conf + keybinds
#   grim slurp swash                             scripts/screenshot.sh
#   hyprpicker                                   keybinds.conf color picker bind
#   alacritty                                    defaults.conf $terminal/$filemanager
#   ai-usagebar-bin  (AUR)                       Noctalia felipeartur/ai-usagebar widget
#                                                (the widget renders only a glyph
#                                                without this CLI on PATH)
#
# waybar is installed for host parity, though Noctalia replaced it as the
# active bar. Remove it only if intentionally trimming this workstation set.
# OpenRazer runs for the connected Viper Mini; add the user to the `openrazer`
# group and start a fresh login session before enabling its user service.
