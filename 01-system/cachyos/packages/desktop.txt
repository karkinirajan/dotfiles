# Hyprland + Noctalia desktop packages
#
# Desktop session, host greeter, hardware integration, and the directly
# installed desktop applications on the primary CachyOS workstation.
#
# Install the combined baseline package lists using the interactive commands
# in the root README. That flow supports either paru or yay for AUR packages.
#
# Referenced directly by config:
#   hyprland hyprlock hypridle hyprpolkitagent   02-desktop/hyprland/hypr/*.conf
#   greetd noctalia-greeter uwsm                 active Noctalia greeter + UWSM session
#   noctalia                                 the bar/launcher/notifications
#   cachyos-wallpapers                          Noctalia's selected CachyOS Moon wallpaper
#   hyprsunset                                   scripts/nightlight-toggle.sh
#   hyprpm                                       plugin reload in autostart.conf
#   cliphist wl-clipboard                        autostart.conf + keybinds
#   grim slurp satty swash                       scripts/screenshot.sh
#   hyprpicker                                   keybinds.conf color picker bind
#   alacritty                                    defaults.conf $terminal/$filemanager
#   ai-usagebar-bin  (AUR)                       Noctalia felipeartur/ai-usagebar widget
#                                                (the widget renders only a glyph
#                                                without this CLI on PATH)
#
# Dependencies that are not listed on purpose: hyprcursor, hyprgraphics, hyprlang, hyprutils and
# hyprwayland-scanner arrive through hyprland, hyprlock and hyprpm.
#   ddcutil qt6ct       settings.toml [brightness] uses ddcutil; uwsm/env sets QT_QPA_PLATFORMTHEME=qt6ct
#   xdg-desktop-portal-gtk   hyprland-portals.conf prefers hyprland;gtk (file chooser)
#   bibata-cursor-theme-bin (AUR) the Bibata-Modern-Ice cursor named in uwsm/env and
#                       environment.conf; the bare name lets paru pick the Material provider
#   gnome-keyring       Secret Service for the gh login, Chrome, Brave and Electron apps (chapter 19.6)
#   swash                    CachyOS repo or AUR only; it is not in Arch extra
#   mailspring              CachyOS repo has an older build than the AUR; check the version you want
#   google-chrome (AUR)     the default browser (mimeapps.list, BROWSER in uwsm/env and .zshrc)
#   zen-browser-bin         CachyOS repo; a Firefox-based second browser
#
# Removed on 2026-11-11 and 2026-11-12, see 01-system/cachyos/workstation-changes.md:
# waybar (Noctalia is the only bar), sddm (greetd is the login manager, the SDDM
# presets stay in 02-desktop/hyprland/sddm/ as reference) and the unused desktop
# applications.
# OpenRazer runs for the connected Viper Mini; add the user to the `openrazer`
# group and start a fresh login session before enabling its user service.
