# Font packages
#
# Font FILES are deliberately not tracked in this repo: they are large, binary,
# and every one of them is a package away. This list is the reproducible part.
# Lines marked (AUR) are not in the official repos and need an AUR helper.
#
# Install the combined baseline package lists using the interactive commands
# in the root README. That flow supports either paru or yay for AUR packages.
#
# ── Required by the configs in this repo ─────────────────────────────────────
#   ttf-firacode-nerd     kitty font_family / bold_font, plus the symbol_map
#                         ranges kitty.conf declares for powerline + devicons.
#                         Also the Noctalia system-monitor widget.
#   ttf-jetbrains-mono    Noctalia bar font_family ("JetBrains Mono" and
#                         "JetBrains Mono Medium").
#   ttf-dejavu            Hyprland misc.font_family, groupbar and splash.
#   noto-fonts-emoji      emoji in notifications, tooltips and the terminal.
#   ttf-weather-icons     (AUR) Noctalia weather widget glyphs.
#
# Everything else is a desktop/toolkit dependency or a spare face.
