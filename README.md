# My Development Environment Configuration

This repository contains my personal configuration files and setup guides for developing across Linux and macOS systems.

## Repository Structure

```bash
dotfiles/
├── backend/           # Backend development configs and guides
│   ├── deploy-django-production.md
│   └── django-querysets.md
├── databases/         # Database setup and configuration
│   └── postgresql-setup-linux.md
├── git-github/        # Version control guides
│   └── git-commands.md
├── linux/             # Linux-specific configurations
│   ├── arch/          # Arch Linux configs (.bashrc, .zshrc)
│   ├── ubuntu/        # Ubuntu configs (.zshrc)
│   └── starship.toml  # Terminal prompt customization
├── mac/               # macOS-specific configurations (.zshrc)
├── neovim/            # Neovim editor configuration and guides
│   ├── README.md
│   └── docs/          # Comprehensive development setup guides
│       ├── 01-installation.md
│       ├── 02-plugin-manager.md
│       ├── 03-lsp-setup.md
│       ├── 06-mern-stack.md
│       ├── 07-python-setup.md
│       ├── 09-sql-databases.md
│       ├── 10-nosql-databases.md
│       ├── 11-docker.md
│       ├── 12-kubernetes.md
│       ├── 13-terraform.md
│       ├── 16-debugging.md
│       └── INDEX.md
├── sublime/           # Sublime Text editor settings
│   ├── anaconda-sublime.json
│   ├── sublime-repl.json
│   └── sublime-settings.json
└── vscode/            # Visual Studio Code settings
    ├── vscode-extensions.json
    ├── vscode-keybindings.json
    └── vscode-settings.json
```

## Key Components

- **Backend Tools**: Django deployment guides and query optimization
- **Editor Configurations**: Settings for VSCode, Sublime Text, and Neovim
- **Neovim Development Setup**: Comprehensive guides for setting up development environments including:
  - LSP setup and configuration
  - MERN stack development
  - Python development
  - SQL and NoSQL databases
  - Docker, Kubernetes, and Terraform
  - Debugging tools and workflows
- **Shell Customization**: Terminal prompt with Starship and shell configurations for Arch, Ubuntu, and macOS
- **Version Control**: Git command reference and best practices
- **Database Setup**: PostgreSQL installation and configuration
- **Cross-Platform Configurations**: Tailored settings for Linux (Arch, Ubuntu) and macOS
